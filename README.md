\# 🥱 Academic Sleep Generator



> \*An unnecessarily elaborate solution for the critically underreported problem of educational content being too interesting.\*



\*\*Transform your academic materials into maximum-monotony learning experiences.\*\* Because sometimes, the best way to master a subject is to read about it until your eyelids gain sentience.



\---



\## 🎯 The Problem (That Definitely Exists)



Let's be honest: educational content can be dangerously \*engaging\*. Students are at risk of:



\- ✓ Accidentally understanding complex topics

\- ✓ Developing unwanted curiosity

\- ✓ Staying alert during late-night study sessions

\- ✓ Enjoying their homework (the horror)



\*\*The Academic Sleep Generator™ solves this with clinical precision.\*\*



\---



\## 💊 The Solution (That Everyone Needs)



Enter your academic level, subject, and topic. Watch as our AI transforms it into the most exhaustingly detailed, boringly formatted, needlessly verbose explanation known to education.



\### Core Features



| Feature | Description |

|---------|-------------|

| \*\*AI-Powered Dry Generator\*\* | Transforms any topic into academic wallpaper-grade content |

| \*\*Make It Drier\*\* | Progressive boredom escalation (5 levels of increasing tedium) |

| \*\*Sleep Pill\*\* | Generates a random obscure academic topic to shock your brain back to sleep |

| \*\*Distraction-Free Mode\*\* | Clean, minimal interface—just walls of text |

| \*\*Customizable Experience\*\* | Font sizes, reading speed, academic preset levels |

| \*\*Lofi Ambience\*\* | Background audio to enhance the sleepy vibes |

| \*\*Copy-to-Clipboard\*\* | Export your acquired boredom to notes apps |

\## 📦 Installation \& Setup



\### Prerequisites



\- \*\*Node.js\*\* (v16 or higher)

\- \*\*npm\*\* or \*\*yarn\*\*

\- \*\*Git\*\*

\- API Key for Claude (get one at \[Anthropic Console](https://console.anthropic.com))



\### Step 1: Clone the Repository



```bash

git clone https://github.com/\[username]/academic-sleep-generator.git

cd academic-sleep-generator

```



\### Step 2: Install Dependencies



\*\*Backend:\*\*

```bash

cd backend

npm install

```



\*\*Frontend:\*\*

```bash

cd ../frontend

npm install

```



\### Step 3: Configure Environment Variables



Create a `.env` file in the `backend` directory:



```env

PORT=5000

CLAUDE\_API\_KEY=your\_api\_key\_here

```



Create a `.env` file in the `frontend` directory:



```env

VITE\_API\_BASE\_URL=http://localhost:5000/api

```



\### Step 4: Start the Development Servers



\*\*Terminal 1 - Backend:\*\*

```bash

cd backend

npm run dev

```



\*\*Terminal 2 - Frontend:\*\*

```bash

cd frontend

npm run dev

```



The application will be available at `http://localhost:5173` (Vite default).

\## 🚀 Usage



\### Basic Workflow



1\. \*\*Select Your Academic Level\*\*

&#x20;  - High School

&#x20;  - Undergraduate

&#x20;  - Graduate

&#x20;  - PhD-Level Suffering



2\. \*\*Choose a Subject\*\*

&#x20;  - STEM, Humanities, Social Sciences, etc.



3\. \*\*Enter Your Topic\*\*

&#x20;  - Any subject you'd normally find interesting



4\. \*\*Generate Dry Content\*\*

&#x20;  - AI generates ultra-verbose, unnecessarily detailed explanation



5\. \*\*Escalate with "Make It Drier"\*\*

&#x20;  - Each click adds more:

&#x20;    - Tangential definitions

&#x20;    - Obsolete historical context

&#x20;    - Unnecessarily technical jargon

&#x20;    - Repeated concept restatement



6\. \*\*Deploy the Sleep Pill\*\*

&#x20;  - When all else fails, generate a random topic

&#x20;  - Guaranteed to be incomprehensible and unrelated



\### Advanced Features



\- \*\*Read Aloud\*\*: Hear the monotony spoken back to you

\- \*\*Night Mode\*\*: Protect your remaining consciousness

\- \*\*Session History\*\*: Track your descent into academic boredom

\- \*\*Export to PDF\*\*: Share your cure with classmates

\## 🎮 How "Make It Drier" Works



\*\*Level 1:\*\* Standard academic explanation  

\*\*Level 2:\*\* Add tangential definitions and synonyms  

\*\*Level 3:\*\* Include historical context (even if irrelevant)  

\*\*Level 4:\*\* Maximum jargon saturation  

\*\*Level 5:\*\* \*The academic void\* (incomprehensible even to experts)



Each escalation adds approximately 40% more words and 60% more tedium.
